# راهنمای استقرار سرور ورکر در Cloudflare (Cloudflare Worker Deployment)

این راهنما دو روش سریع برای راه‌اندازی سرور **TWP** در کلادفلر را آموزش می‌دهد:
1. **روش وب داشبورد (سریع‌ترین - بدون نیاز به ترمینال)**
2. **روش خط فرمان با Wrangler CLI (مخصوص توسعه‌دهندگان)**

---

## روش اول: از طریق پنل وب Cloudflare (پیشنهادی)

### ۱. ورود به داشبورد
- وارد حساب کاربری خود در [dash.cloudflare.com](https://dash.cloudflare.com) شوید (اگر اکانت ندارید، ثبت‌نام رایگان است).

### ۲. ساخت ورکر جدید
1. از منوی سمت چپ به بخش **Workers & Pages** بروید.
2. روی دکمه آبی‌رنگ **Create Application** کلیک کنید.
3. در تب Workers، روی **Create Worker** بزنید.
4. یک نام دلخواه برای ورکر انتخاب کنید (مثلاً `my-tg-worker`) و روی **Deploy** کلیک کنید.

### ۳. قرار دادن کد `worker.js`
1. در صفحه جزئیات ورکر، روی دکمه **Edit code** (ویرایش کد) کلیک کنید.
2. تمام کدهای پیش‌فرض داخل ادیتور را پاک کنید.
3. کل محتویات فایل [worker.js](../worker.js) را کپی کرده و در ادیتور پیست نمایید.
4. در بالا سمت راست دکمه **Save and Deploy** را بزنید.

### ۴. (اختیاری) تنظیم رمز عبور / سکرت برای جلوگیری از استفاده دیگران
اگر می‌خواهید فقط خودتان یا افراد مجاز به ورکر متصل شوند:
1. به صفحه تنظیمات ورکر بروید: **Settings** -> **Variables and Secrets**.
2. روی **Add** کلیک کرده و نام متغیر را `SECRET` بگذارید.
3. مقدار آن را یک رمز دلخواه (مثلاً `MySecurePassword123`) تعیین کرده و Save کنید.
4. اکنون کاربر هنگام اضافه کردن پروکسی باید این رمز را در فیلد Secret وارد کند.

---

## روش دوم: با دستورات Wrangler CLI

اگر روی سیستم خود Node.js دارید، با ۳ دستور زیر ورکر را دیپلوی کنید:

```bash
# ۱. کلون کردن مخزن TWP
git clone https://github.com/your-username/TWP.git
cd TWP

# ۲. ورود به اکانت کلادفلر
npx wrangler login

# ۳. دیپلوی مستقیم
npx wrangler deploy
```

پس از پایان، آدرس دامنه شما در ترمینال چاپ می‌شود (مثلاً `https://telegram-worker-proxy.your-name.workers.dev`).

## تست آنلاین بودن ورکر
می‌توانید با اسکریپت داخلی پروژه سلامت و پینگ ورکر خود را بسنجید:

```bash
node scripts/test-worker.js your-worker.workers.dev [secret]
```
