# راهنمای استقرار سرور ورکر در Cloudflare (Cloudflare Worker Deployment)

این راهنما آموزش گام‌به‌گام راه‌اندازی هسته **TWP v2.0 (Official Telegram WEB Proxy)** روی Cloudflare Workers را شرح می‌دهد. با استقرار این ورکر، مستقیماً لینک رسمی اتصال تلگرام (`tg://webproxy`) را بدون نیاز به هیچ سرور VPS دریافت خواهید کرد.

---

## روش اول: از طریق پنل وب Cloudflare (سریع‌ترین - بدون نیاز به ترمینال)

### ۱. ورود به داشبورد
- وارد حساب کاربری خود در [dash.cloudflare.com](https://dash.cloudflare.com) شوید (ثبت‌نام رایگان است).

### ۲. ساخت ورکر جدید
1. از منوی سمت چپ به بخش **Workers & Pages** بروید.
2. روی دکمه آبی‌رنگ **Create Application** کلیک کنید.
3. در تب Workers، روی **Create Worker** بزنید.
4. یک نام دلخواه برای ورکر انتخاب کنید (مثلاً `my-tg-proxy`) و روی **Deploy** کلیک کنید.

### ۳. کپی کردن کد `worker.js`
1. در صفحه جزئیات ورکر، روی دکمه **Edit code** کلیک کنید.
2. تمام کدهای پیش‌فرض داخل ادیتور را پاک کنید.
3. کل محتویات فایل [`worker.js`](../worker.js) را کپی کرده و در ادیتور پیست نمایید.
4. در بالا سمت راست دکمه **Save and Deploy** را بزنید.

### ۴. (اختیاری) تنظیم متغیرهای محیطی
در تب **Settings** -> **Variables and Secrets**:
- `PROXY_SECRET` (یا `SECRET`): کلید ۱۶ بایتی هگز (پیش‌فرض خودکار: `000102030405060708090a0b0c0d0e0f`). در صورتی که این متغیر را ست نکنید، ورکر با همین سکرت پیش‌فرض کار خواهد کرد.
- `MAX_DIALS`: (اختیاری) حداکثر تعداد دایل به دیتاسنتر به ازای هر سوکت (پیش‌فرض: `45`).

### ۵. اتصال به تلگرام
لینک اتصال وب‌پروکسی شما به شکل زیر آماده است:
```text
tg://webproxy?server=your-worker-name.your-subdomain.workers.dev&secret=000102030405060708090a0b0c0d0e0f
```
این لینک در نسخه‌های جدید تلگرام (اندروید ۱۲.۱۰ به بعد و دسکتاپ ۷.۱ به بعد) به صورت مستقیم شناسایی شده و تلگرام به آن وصل می‌شود.

## روش دوم: با دستورات Wrangler CLI

اگر روی سیستم خود Node.js دارید، با چند دستور زیر ورکر را استقرار دهید:

```bash
# ۱. کلون کردن مخزن TWP
git clone https://github.com/Qorvhex/TWP.git
cd TWP

# ۲. ورود به اکانت کلادفلر (در صورت نیاز)
npx wrangler login

# ۳. استقرار مستقیم
npx wrangler deploy
```

پس از استقرار، آدرس اختصاصی ورکر در ترمینال چاپ می‌شود. با باز کردن آن در مرورگر یا کلیک بر روی لینک وب‌پروکسی، تلگرام فوراً متصل خواهد شد.
